# overland-labs.com

The Overland Labs studio website, served by GitHub Pages at https://overland-labs.com.

Plain static files, with no build step:
- `index.html`: the home page
- `terms.html`, `privacy.html`, `refunds.html`: the legal pages
- `style.css`: the styles
- `topo.svg`: the hero's topographic map

Edit a file and push to `main`, and Pages publishes it within a minute or two. The Terms, Privacy and Refunds pages mirror the legal draft. Change the draft first, then the page.
